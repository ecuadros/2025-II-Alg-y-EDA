\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename Trait$>$\newline
class BTree$<$ Trait $>$}
Implementación de un árbol B genérico. 

Esta clase implementa un árbol B (\doxylink{classBTree}{BTree}) con soporte para inserción, eliminación, búsqueda y serialización en formato binario. Es una implementación flexible que permite especificar el orden del árbol y si los elementos deben ser únicos.
