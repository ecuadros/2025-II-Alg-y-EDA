Detailed Description

template<typename T>
class CVector< T >

Vector dinámico inspirado en el enfoque del curso/libro.

Template Parameters
TTipo de dato almacenado.

Características:

  • Inserción amortizada con resize() cuando hay desbordamiento.
  • Crecimiento lineal (delta>0) o multiplicativo (delta==0).
  • Gestión segura de memoria (destructor) y semántica de copia/movimiento.
