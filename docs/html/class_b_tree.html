Detailed Description

template<typename Trait>
class BTree< Trait >

Implementación de un B-Tree con inserción, búsqueda, borrado y concurrencia.

Template Parameters
TraitDebe definir keyType, ObjIDType y struct Compare { bool operator()(const keyType&, const keyType&) const; }.
Características
  • Concurrencia: protecciones con std::shared_mutex en operaciones públicas.
  • Persistencia: Save y Load para escribir/leer el árbol.
  • Recorridos: ForEachT (genérico), Print, e iteradores forward/reverse.
