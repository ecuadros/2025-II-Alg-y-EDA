Detailed Description

template<typename Trait>
class BTree< Trait >

Implementación de un árbol B genérico.

Esta clase implementa un árbol B (BTree) con soporte para inserción, eliminación, búsqueda y serialización en formato binario. Es una implementación flexible que permite especificar el orden del árbol y si los elementos deben ser únicos.
